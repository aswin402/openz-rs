24/7 Production Deployment Runbook

Deploy OpenZ as an autonomous system service running continuously under systemd:

# 1. Install OpenZ binary globally ./localinstall.sh --balanced # 2. Configure systemd unit (/etc/systemd/system/openz.service) [Unit] Description=OpenZ 24/7 Autonomous AI Agent Daemon After=network.target [Service] Type=simple User=aswin ExecStart=/home/aswin/.cargo/bin/openz gateway --port 8765 --host 127.0.0.1 Restart=always RestartSec=5s LimitNOFILE=65535 [Install] WantedBy=multi-user.target # 3. Enable and start daemon sudo systemctl daemon-reload sudo systemctl enable --now openz.service
